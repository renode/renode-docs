# External control client

Renode exposes an API server that can be used to control the emulation programatically using the [External control client library](https://github.com/renode/renode/tree/master/tools/external_control_client).
Latest building instructions and example descriptions can be found in the [README file](https://github.com/renode/renode/blob/master/tools/external_control_client/README.md) in Renode's repository.
